
# Task Manager

Desktop-приложение для создания и управления задачами на Python с использованием PyQt6.

## Возможности

- Создание задач
- Ввод названия и описания
- Выбор приоритета: Low, Medium, High
- Дополнительные настройки: Important, Send notification
- Хранение задач в списке Python
- Очистка формы
- Удаление последней задачи
- Отображение количества созданных задач

## Установка

Установите PyQt6:

```bash
py -m pip install PyQt6
```

## Запуск

```bash
py main.py
```

## Используемые технологии

- Python
- PyQt6
- Qt Widgets
- Layouts
