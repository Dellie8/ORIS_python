
# Многопоточный сервер задач

## Описание

Программа представляет собой многопоточный TCP-сервер,
предназначенный для управления списком задач.

Несколько клиентов могут одновременно подключаться
к серверу и работать с общим списком задач.

## Используемые технологии

- Python
- socket
- threading
- json

## Запуск программы

1. Открыть папку проекта.
2. Запустить сервер:

   python server.py

3. Открыть второе окно терминала.
4. Запустить клиента:

   python client.py

Для проверки многопоточности можно запустить несколько
клиентов в разных окнах терминала.

## Команды

- /add <текст> — добавить задачу.
- /list — вывести список задач.
- /done <номер> — отметить задачу выполненной.
- /delete <номер> — удалить задачу.
- /quit — завершить соединение.

## Многопоточность

Для обработки нескольких клиентов одновременно
используется библиотека threading.

При подключении каждого нового клиента сервер
создаёт отдельный поток с помощью threading.Thread.

Таким образом, несколько пользователей могут
работать с сервером одновременно.

## Синхронизация

Для защиты общего списка задач используется
threading.Lock().

Блокировка предотвращает одновременное изменение
списка несколькими потоками.

Конструкция with tasks_lock обеспечивает
автоматическое освобождение блокировки после
завершения защищённого участка кода.

## Структура задачи

Каждая задача представлена словарём:

- text — текст задачи;
- done — статус выполнения.

Все задачи хранятся в общем списке на сервере.
